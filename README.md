# GAL-Prompt-Panel V1.0

手机优先的原创成年女性角色提示词组合工具。纯 HTML、CSS、JavaScript，无框架、无 npm、无后端、无外部资源。

## 运行

将五个文件放在同一文件夹，直接双击 `index.html`，使用 Edge、Chrome、Safari 或 Firefox 打开。无需安装依赖或启动服务。手机需要在支持本地网页脚本的浏览器中打开整套文件；文件管理器的静态预览可能不运行 JavaScript，也可以将五个文件放入任意静态网站后用手机访问。

## 使用

- 选择角色与选项，短句和完整 Prompt 实时生成。桌面左右布局，手机纵向排列，底部始终提供两个复制按钮。
- 场景、姿势、服装选“自定义”后可输入文字；追加词放在构图段末尾，保证固定 17 段顺序。
- 完整 Prompt 可以手动修改并自动保存；再次修改任意选项或重新生成会替换手动版本。
- “全部强锁”勾选六项约束。三人固定左奈奈、中姬、右爱；三人不同表情为奈奈开心笑、姬温柔微笑、爱害羞。单人选择该选项时只采用自己的对应表情。
- 推荐组合覆盖其指定选项，保留其他选择。机库扶帽通过自定义姿势实现。
- 随机只改变场景、姿势、表情、焦段、机位、角度、景别、服装、光线、时间、天气、发型造型，不改变角色、Master、画风、比例、强化或参考权限。
- “清空”清除自定义输入与手动编辑，将搭配恢复默认；保留当前角色、最近使用及 Master。
- 复制成功、重新生成、推荐或随机搭配时记入最近使用，按短句去重，最多保留十条；点击可恢复当时选项。最近使用保存选项，不保存手动修改的全文。
- 本地保存包含最后选择、自定义词、当前可编辑全文和最近记录。数据仅在当前浏览器存储；隐私模式、清除浏览数据或移动文件可能导致记录不可用。存储受限时仍可操作。
- 复制优先使用剪贴板 API；在本地文件或权限受限时尝试兼容复制；都失败时选中内容，手动长按或 Ctrl+C 复制。

时间与天气独立选择，默认“下午 / 晴天”。短句在场景后显示时间、天气；完整 Prompt 按“场景 → 时间 → 天气 → 光线”输出。场景切换和推荐组合不会自动修改时间或天气；随机搭配可随机两项。旧版本地记录缺少这两个字段时自动补默认值，已手动编辑的全文仍保留。

发型默认“默认发型”，完全遵循当前角色正式头发设定。其他六项只改变局部造型，保留发色、基础发长和人物身份；短发盘束采用合理局部适配。短句在角色后显示发型，完整 Prompt 在 HAIR 后新增“发型变化”（第 5 段）。三人分别适配自己的发型。随机池包含全部七项，旧记录缺少 hairStyle 时补“默认发型”。锁发型仍保护角色头发身份；非默认变化仅允许所选局部造型。

## 正式角色 Master

已在 `prompt-data.js` 的 `characters` 中录入三位角色完整正式文本。奈奈遵循 NANA FACE MASTER V1 → NANA BODY MASTER V1 → NANA HAIR MASTER V1；姬的 FACE / BODY / HAIR 与整体身份均来自唯一的 JI CHARACTER SHEET V1；爱遵循 AI FACE MASTER V1 → AI BODY MASTER → AI HAIR MASTER V1。角色身份及三项设定优先于画风、参考图、服装、姿势、场景与光线。单人只输出当前角色；三人按奈奈、姬、爱分别输出独立 FACE / BODY / HAIR 块，放在角色身份段，后续三段引用这些设定，保留 17 段顺序。

内容参考只读取所选服装／姿势／构图／场景／站位，不继承 FACE、BODY、HAIR、发色或身份。本工具生成文字，不上传图片，也不调用生图服务。

旧版 localStorage 键与数据结构保持兼容。打开页面时，未手动编辑的全文自动使用最新 Master 重建；已手动编辑的全文原样保留，可点击“重新生成 Prompt”应用最新设定。最近使用恢复时也读取最新 Master。

## 文件与扩展

### 画风系统

七种画风使用 `styles[名称] = { short, prompt, tags }`，完整描述实际输出到第 16 段“画风”。柔艳GAL仍为默认，融合柔写的脸部、皮肤、体积与成熟气质，以及艳丽的眼睛、发丝、材质与精修感。生成逻辑也兼容旧的字符串画风。

画风下方可多选十项附加强化，作为修饰追加到画风段，短句也会显示所选强化。场景推荐仅显示提示，不会自动修改画风。随机搭配保持画风和强化不变。

高精GAL作为精修等级：先选基础画风，再选择高精GAL，会保留前一画风并叠加精修；默认基础为柔艳GAL。电影GAL带入柔艳GAL的人物精修基础，再加入电影环境光影。`foundation` 指定人物表现基础，`kind: 'quality'` 标记精修等级。

本地保存沿用原有键和结构，在选项中新增 `styleBase`、`styleEnhancements`，旧记录缺少字段时自动补默认值。最近使用同时保存强化和基础画风，清空恢复默认。角色 Master 文本保持不变，优先级为 CHARACTER / FACE / BODY / HAIR > STYLE > 参考图服装与姿势 > 场景与光线。

| 文件 | 用途 |
| --- | --- |
| index.html | 页面结构 |
| style.css | 深色界面与响应式布局 |
| app.js | 通用选项渲染、状态、生成、复制与存储 |
| prompt-data.js | 角色 Master、全部选项、推荐组合、模板与默认值 |
| README.md | 运行和扩展说明 |

添加凛、可可、莎莎、可乐：在 `characters` 加入独立 id、name、short、symbol、master，并在 `presets` 添加推荐；需要时补充 `expressionsByCharacter`。通用角色按钮无需更改。添加画风需同时扩展 style 选项及 styles 描述；强化项集中在 styleEnhancements，场景推荐集中在 styleRecommendations。

新增发型库、表情 Sheet、姿势库可添加数据字段／选项组与默认值；在 app.js 的 buildPrompt 中映射至对应固定段落，按需加入 randomKeys。发型库需要明确是否覆盖发型锁。合照成员和站位由 members、positions 定义，避免将角色绑定写死在生成逻辑中。

## 手动验收

1. 双击 index.html，检查默认柔艳GAL、35mm、9:16。
2. 切换角色、推荐、普通选项、自定义输入与强化按钮，检查高亮及全文同步。
3. 三人选择不同表情，检查站位和三人表情；检查全文 17 段顺序。
4. 分别复制短句和手动编辑的全文，粘贴到文本编辑器验证。
5. 刷新页面，检查选择、输入、手动全文、十条历史恢复。
6. 多次随机，检查角色／画风／比例／参考模式不变。
7. 在 375px、390px、768px 与桌面宽度检查布局、触摸按钮及底部安全区。

## 扩展服装

保留原有服装，新增 6 项泳装、11 项性感／轻熟、6 项绝对领域和 13 项 COS（含自定义 COS）。全部可由随机搭配抽取。绝对领域输出裙袜之间大腿清楚可见、禁用连裤袜和长靴遮挡的规则；若需要在成图中完整展示，选择能覆盖大腿的景别。COS 只改变服装、配饰与主题，不使用原作人物脸或头发。

选择“自定义 COS”显示独立输入框，内容输出到短句和服装段，并保存到 customCos；与原有自定义服装输入分别保留。旧记录缺少字段时默认为空。随机抽到自定义 COS 时沿用已填内容，未填写时显示“待填写”，可继续输入。所有服装均适配成年角色自身身体设定。

## V1.0 配置管理

- 常用选项默认展开，高级选项默认折叠；点击标题切换，折叠状态自动保存。折叠不会取消选择或停止参与生成，全部选项仍可用。
- 填写可选收藏名称后点击“收藏当前组合”，保存全部选项与当前手动编辑全文。点击收藏恢复，点击对应“删除”移除；清空搭配不删除收藏。
- 导出配置 JSON 包含当前选项、全文、编辑状态、收藏、最近使用及折叠状态，不包含角色 Master 或内容库。
- 导入接受 V1.0 导出文件及旧版 localStorage 配置对象；恢复当前组合并合并收藏与最近使用，重复收藏去重，最近使用最多十条。导入文件上限 5 MB，格式不正确时不修改当前配置。旧记录缺少新增字段时采用默认值。
- 手机按钮增加间距并保持大触摸区域；底部操作栏预留安全区。长 Prompt 在固定高度内独立滚动，可点“回到开头”或“查看末尾”，手机编辑时使用 16px 字号。

继续双击 index.html 即可使用，无需安装、联网或运行服务。
